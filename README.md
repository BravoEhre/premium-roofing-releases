# Premium Roofing — installers

The installers for the Premium Roofing desktop app, for Windows and Apple
computers. Each release here is one version.

Premium Roofing's people install the app from their account, and the app
keeps itself up to date from there. There is nothing to build in this
repository and no source code in it: only the installers, under
[Releases](../../releases).

The app is for Premium Roofing's own team. It opens to a sign-in, and an
account comes by invitation from their office.
